# LivelyWalk

A marketplace where remote travelers book local guides to physically walk a route while streaming live video.

🌐 [livelywalk.com](https://livelywalk.com)
🗺️ [Our journey](https://livelywalk.com/roadmap) — where we've been, where our ambition points

## Latest test builds

- [Guide app (Android APK, stable)](https://github.com/LivelyWalk/livewalk-guide/releases/tag/latest-release) · [beta](https://github.com/LivelyWalk/livewalk-guide/releases/tag/latest-test-build)
- [Traveler app (Android APK, stable)](https://github.com/LivelyWalk/livewalk-traveler/releases/tag/latest-release) · [beta](https://github.com/LivelyWalk/livewalk-traveler/releases/tag/latest-test-build)
- [Traveler web app](https://app.livelywalk.com) · [beta](https://beta.livelywalk.com)

Each Android link always points at the newest build — open it on the phone and tap **Install**, or scan its QR code. The web links open directly in your browser. All builds are also listed on the [download hub](https://downloads.livelywalk.com).
